# **App Name**: Manhwa Scribe

## Core Features:

- OCR Import: Import text from Manhwa images using OCR technology.
- Translation Editor: Provide tools for correcting and editing the translated text, using a side-by-side view.
- AI Text Analysis: Offer AI-powered suggestions for translation improvements and contextual understanding of phrases or panels, and present it to the translator as a tool for their decision-making.
- Export Translation: Export edited translations in a specified format. Allow formats such as .txt, .srt, and .docx
- Image Handling: Offer a panel cropping tool for precise image handling. Images can be cropped or split as necessary
- Theme Toggle: Enable a dark and light mode for better usability across environments

## Style Guidelines:

- Primary color: Soft green (#A7D1AB) to convey productivity and ease, leaning away from overly vibrant tones.
- Background color: Light grey (#F0F0F0), ensuring a clean and non-distracting interface that supports long periods of focus. This scheme lends itself to a light mode appearance.
- Accent color: Muted olive (#808000) for buttons and important UI elements, for contrast without being distracting.
- Body and headline font: 'Inter' sans-serif, providing clarity and modernity in text display.
- Use minimalist, consistent icons for main tools to facilitate easy recognition and a clutter-free interface.
- Maintain a clean, productivity-focused layout. The primary layout will contain a prominent panel to view and crop/manipulate a manwha page, a side-by-side panel to view original and translated text, and a control bar.
- Incorporate subtle transitions for text updates or panel shifts.
